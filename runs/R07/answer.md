# 判断

附件不足以支持“CrabNet 在不同材料性质任务上普遍优于比较方法，因此可以直接用于未见化学体系的新材料筛选”这一完整推论。更准确的结论是：**在论文选定的28个组成输入回归基准及其处理、划分和默认训练条件下，CrabNet具有广泛竞争力，整体与Roost相近，通常优于本研究的ElemNet和RF基线；未见化学体系的筛选可靠性仍需目标任务验证。** 摘要原话是“matches or exceeds…nearly all”，包含相当与例外，并非全面严格领先。[C01][C08][C09][C19]

这不否定将CrabNet作为只有组成时的候选预测工具；它支持先试用和验证，尚不支持凭论文MAE直接信任跨体系筛选排序或发现新材料。[C02][C19][C21]

# 原文证据及实际支持范围

文献是 *Compositionally restricted attention-based network for materials property predictions*，npj Computational Materials (2021) 7:77，DOI 10.1038/s41524-021-00545-1。此次材料为10页论文PDF及带块编号的全文定位文本，未附Supplementary Information；未联网核查版本沿革或勘误，因此不声称这是已核对勘误后的版本。下列位置均为附件PDF页序；所引页的印刷页码一致。claims.json中保存连续原文引文。

**输入确实符合“有组成、无结构”的情形。** 模型用原子序数和元素分数含量建立元素及分数嵌入，再通过自注意力更新元素表征。默认CrabNet使用mat2vec元素嵌入；HotCrab用one-hot，并非默认模型完全没有预先化学信息。研究有意忽略已有结构信息。因此只有化学式可以运行该类模型，但不能由此推得它能区分同组成的不同晶体结构、相或加工状态。[C02][C10][C20]（PDF 6页，p06-b01—b03）

**数据广泛，但范围有限。** 28个任务来自Matbench的10个与Extended的18个，兼有实验和计算数据，规模312—341788条，包括带隙、形成能/焓、弹性模量、热性质等回归目标；并未在此评测中证明分类或全部性质任务表现。[C03]（PDF 2页p02-b02、b04；3页表1）

Matbench采用五折，表1列原始训练/验证/测试72/8/20；Extended采用固定随机种子划分，原始比例70/15/15。划分后清除集合内重复组成，并移除跨训练/验证/测试的相同组成，故实际比例可变。重复组成在OQMD和MP取最低形成焓对应的目标，其余取均值。这样减少了精确组成泄漏，也把多结构可能对应的多个标签变成特定聚合目标；**它不等价于把整个元素组合或化学体系隔离到测试集。** [C04][C05][C19][C20]（PDF 2页p02-b02—b03；3页表1，已查看原页图）

**同任务比较较有依据，但训练条件不是完全对称。** Roost、CrabNet、ElemNet、RF用处理后的数据，训练及验证用于训练/调参，测试在调参完成后才评估。主指标是MAE，越低越好；不同性质、单位或log10目标之间不应直接比较MAE大小。[C06] 三种深度模型用各仓库默认设置，但CrabNet默认参数曾在部分同一基准的验证集上优化，作者承认可能有小优势。RF是Magpie组成特征加500棵树。因而“同用默认参数”不保证相等的调参投入。[C07][C22]（PDF 2页p02-b03—b05；8页p08-b02）

# 比较对象与必须保留的例外

1. **Roost是强对照，而非被一致击败。** 正文直接说Roost与两种CrabNet总体相近。[C08] 图1列序经PDF第4页原图核对：MP band gap的MAE为CrabNet 0.263、Roost 0.260；phonon peak为53.341、49.767；MP shear modulus中CrabNet 12.787、RF 12.777。均存在CrabNet不是最优的情况。这些是同一行的比较，不跨性质混合单位，也不表示差值已达到统计显著性。[C09]
2. **嵌入方案也没有一律赢家。** 作者指出mat2vec相对one-hot的优势有AFLOW热导率、MP弹性各向异性及最大OQMD数据集等例外；图1亦有接近和相等结果，不能把OQMD整体概括写成每项HotCrab严格胜出。[C10] ElemNet在phonons和steels_yield等任务未收敛，NaN不能当成零误差或计算胜出幅度。[C22]（PDF 2页p02-b05；4页图1；8页p08-b01）
3. **Automatminer只在两个组成可比任务重点对照。** 其余模型用结构信息，故论文不把它们的分数放入图1。expt_gap正文报告Automatminer 0.416 eV、CrabNet 0.338 eV；steels_yield为95.2、91.7，正文单位写GPa，图1的CrabNet更精确值为91.748。保留正文标法，但绝对单位应回到原始标签确认，不能自行更正或用它直接设筛选阈值。[C11][C12]（PDF 2页p02-b05—b06；4页图1）
4. **IRNet是外文献结果，不是本研究同条件重训。** 作者因计算资源未重训IRNet。引用的IRNet vs HotCrab带隙MAE为0.047 vs 0.048 eV，反而IRNet数值更低；另外三项形成焓、每原子能量、每原子体积则HotCrab较低。不能照抄笼统优势措辞，且该段不足以证明跨论文划分和预处理完全可比。[C13]（PDF 8页p08-b02）

# 重复训练、误差条与外推

论文并非完全没有重复训练说明：steels_yield段明确称重复训练和验证始终优于Automatminer的95.2结果，但没有在该段量化重复次数和分布。[C15] Methods又说明CrabNet所有性质训练固定种子42，以减小Transformer初始化差异，并明确未研究借随机初始化差异确定epistemic uncertainty。固定种子复现、交叉验证和多独立初始化评估是不同证据，不能互相替代。[C14]（PDF 3页p03-b01；7页p07-b04—b05）

模型确实输出aleatoric uncertainty，图5灰色区域也如此标注；不能把它当成已经校准的新体系分布外可靠性或多种子误差条。就此次正文及图表，无法确认逐任务多种子方差、显著性、未见化学体系校准或前瞻筛选命中率；补充材料未提供，结论限于本次附件。[C16][C21]

最接近体系迁移的示例是AFLOW带隙模型沿SiₓO₁₋ₓ生成预测曲线，但训练集中已有SiO₂。它展示在体系采样稀少时模型如何预测，不是完全留出Si–O体系，也不是用未见组成的实验/计算真值验证曲线。作者将新体系稀疏采样预测和跨性质迁移学习明确列为未来研究可能性。因此“有趋势图”不能补上“能直接筛出未见体系新材料”的证据缺口。[C17][C18][C19]（PDF 4页p04-b02—b03；6页图5图注）

# 适用条件与最小后续动作

可以把CrabNet作为目标性质的组成基线和候选优先级工具，前提是化学式/分数可靠，目标标签的单位、实验或计算来源及聚合方式与用途一致。若研究对象有显著结构或加工依赖，要承认纯组成预测的歧义；若目标是新化学体系，应先定义“未见”是新化学式、新元素组合还是训练中没有的元素，并按该定义验证。[C02][C05][C19][C20]

最小必要后续阅读按依赖顺序进行：

- 先查本论文Supplementary Methods及目标任务的预分割数据/处理脚本，确认去重顺序、聚合标签、实际样本数、比例与单位；尤其核实steels_yield单位。数据、代码和补充材料位置列在PDF 8页Data/Code Availability与10页Additional Information。本次未取得或运行它们。[C05][C12][C21]
- 只读与目标任务有关的Matbench/Automatminer说明（参考文献36），若拟采用IRNet比较则补读参考文献6，确认输入、划分、标签与调参机会；无需先泛读所有参考文献。[C07][C11][C13]
- 部署前补齐目标体系隔离测试、多个初始化下与Roost及RF的同条件比较，以及筛选所关心的排序/阈值命中和不确定性校准；最终候选再用独立计算或实验核验。它们是针对证据缺口的建议，不是本次已经执行的实验或论文已证明的结果。[C14][C19][C21]
