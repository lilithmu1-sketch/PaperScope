# 普通PDF入口

`scripts/ingest_pdf.py`需要Python 3.10+和pypdf，其余引用/装配工具仅使用标准库。本工具不联网、不安装软件；依赖缺失时使用当前环境已安装pypdf的解释器，或在已有查看器中按页阅读并说明没有运行自动装配。不要为普通导入索取模型API Key。

输入是本地、可合法读取的未加密PDF。`--source-id`为本次唯一ID；可选`--expected-sha256`核对已登记文件，`--title`、`--doi`、`--license`仅填已知信息，不猜测。工具会在全新输出目录复制`source.pdf`，生成`corpus.json`、`pages.json`、`sources.json`及`ingest-provenance.json`。这些是本地工作材料，生成后不自动公开发布。

语料块按物理页编号，如`p001-b001`，每块最多1400个Python Unicode字符。`extracted_page_span`对应`pages.json`该页提取文本的位置，左闭右开；保留提取文本，只将CRLF/CR统一为LF。它不是页面几何坐标或PDF字符对象索引。自动切块可能截断一句话，引用前查看邻块和原页。

阅读大型corpus时先检索主题，再按页或少量相邻块读取；不要一次输出全文JSON后依赖被截断的返回内容。遇到截断，缩小范围补读；未实际读到的内容不能作为“全文没有报告”的依据。

导入状态：

| 状态 | 含义与处理 |
| --- | --- |
| text_extracted，退出码0 | 所有页有足够可提取字符；仍不保证阅读顺序、公式、列或表格正确 |
| partial_text，退出码3 | 部分页提取失败、为空或字符稀少；仅使用可核查部分，回原页检查列出的页 |
| no_extractable_text，退出码3 | 没有可用文本块；不能用空语料编造引用，改用查看器/授权OCR，或说明材料缺口 |
| 错误，退出码2 | 源哈希不符、加密、损坏、缺依赖、非法参数或已有输出目录；先解决实际原因，不覆盖旧记录 |

字符稀少只是一条复核提示，不能据此断言该页一定是扫描页或没有证据。未实现OCR和密码解锁；有合法解密权限时先用现有工具生成授权副本。PDF元数据标题未经出版核验；DOI/许可未知时保留null，不从相似文件名推断。

图表/旋转/双栏/脚注与重要数值须回到原PDF。原图放大工具`render_region.py`的依赖和坐标规则见`numeric-review.md`，与文本导入相互独立。需要复现包时，将实际使用的原PDF、导入provenance及必要页图声明为统一草稿附件；程序不会猜测或搜集外部文件。
