# CrabNet论文核查

**附件不足以支持“普遍优于比较方法，因此可以直接用于未见化学体系筛选”这一完整判断。** 支持的是：CrabNet在本文组成输入、处理后的28个回归基准上总体表现较强，与Roost总体接近，很多任务优于ElemNet及RF；不是逐任务全面领先，更没有由此自动建立未见体系筛选可靠性。可以把它作为只有组成时的候选模型，但直接部署的证据仍不足。[C01][C03][C10][C15][C24]

核查版本为 *Compositionally restricted attention-based network for materials property predictions*，npj Computational Materials (2021) 7:77，DOI 10.1038/s41524-021-00545-1。附件有10页正文PDF、带块编号定位文本和方法说明；没有补充材料。下文页号为PDF页序，本次所看第2—4页印刷页号与页序一致。引用的逐字原文、块号和判断类型见 claims.json；图1数值已查看PDF原图，不能把提取文本中的空缺当作无结果。[C01][C22]

## 实际实验支持范围

输入是元素原子序数和分数含量，模型不要求晶体结构。默认CrabNet以mat2vec表示元素；HotCrab改用one-hot，因此“只有组成输入”与“完全没有化学先验”并非一回事。对题设研究者，输入条件吻合，但相同组成下结构、相或工艺造成的差异不能由这套输入单独区分。[C02][C08][C25] 依据：第6页 Methods，p06-b02—b03；第2页p02-b03。

28个基准包含10个Matbench任务、18个Extended任务，兼有计算和实验数据，规模312—341788，涉及形成能、带隙、弹性、热性质、钢屈服强度等；本文选择回归任务，存在结构信息时也主动忽略。[C03] Matbench是五折交叉验证，表1原始训练/验证/测试比例72/8/20；Extended固定随机种子划分，原始比例70/15/15。[C04] 这些不是保证清洗后不变的比例：作者在划分后去除集合内重复及跨集合相同组成；OQMD和MP取最低形成焓对应的目标值，其他重复目标取均值。[C05] 依据：第2页 Data procurement，p02-b02—b03；第3页表1，p03-b03—b04。

主比较模型共用处理后的数据，训练/验证用于拟合调参，测试留到调参结束后评估。[C06] 指标是MAE，越低越好，量纲及数值尺度随性质而变；图1按行比较，不应把不同任务的MAE直接相加或以跨任务绝对值决定哪个性质更容易。[C07] 但调参机会不完全相同：三种深度模型均采用各自仓库默认参数，CrabNet的默认参数曾在部分同一基准的验证数据上优化；作者认为影响可能小，没有在这里给出等预算调参对照来量化。[C09] RF为Magpie特征、500棵树、其余默认参数，代表该设置的基线。[C08] 依据：第2页 Benchmark comparisons，p02-b03—b05；第8页p08-b02。

## 比较对象、优势与反例

论文自己写的是Roost与两种CrabNet总体相近，不能改写成CrabNet全面胜出。[C10] 第4页图1的直接反例包括（均为MAE，以下数字保持各任务原尺度）：

| 任务 | CrabNet | 更低误差的比较模型 |
|---|---:|---|
| MP band gap | 0.263 | Roost 0.260 |
| Phonon peak | 53.341 | Roost 49.767 |
| AFLOW energy per atom | 0.093 | Roost 0.086 |
| MP elastic anisotropy | 8.263 | Roost 8.082；ElemNet 8.191 |
| MP shear modulus | 12.787 | RF 12.777 |

这些是“不是全面领先”的证据，不是显著性检验；没有跨种子误差条时，小差值尤其不宜解释为稳定优势。[C10][C22] HotCrab也不是始终逊于默认模型：AFLOW热导率2.254对2.318，MP弹性各向异性8.126对8.263，正文另指出最大OQMD数据的例外。[C11] 图1中NaN表示模型未收敛，不能当作零误差或已定义的普通数值；ElemNet的phonons、steels_yield出现该问题（第4页图注p04-b04、第8页p08-b01）。[C26]

Automatminer的重点直接比较仅为expt_gap和steels_yield，其余Automatminer任务使用结构，不能直接当作同信息量比较。[C12] 正文给出Automatminer→CrabNet：带隙0.416→0.338 eV；钢屈服强度95.2→91.7 GPa。[C13] **GPa按论文第2页原文保留，实际数据单位尚未核实**；不能擅自修正，也不宜直接据此设工程阈值。[C23]

IRNet没有在本研究中重新训练。正文引述IRNet→HotCrab的形成焓0.048→0.031 eV、带隙0.047→0.048 eV、每原子能量0.070→0.033 eV、每原子体积0.394→0.277 Å³。带隙一项HotCrab稍差，限制了正文总体优越措辞；不同论文的划分处理是否一致仍待核查，不能视为同一实验的公平胜负。[C14] 依据：第8页 Reference models，p08-b01—b02。

## 未见体系与不确定性

**推断：** 相同化学式排重只控制组成重复，不等于把整个元素组合或化学家族留在训练之外；五折/随机留出上的强表现不能直接证明新体系外推。[C15] 论文第4页Si–O带隙扫描是模型预测可视化，训练中该体系已有SiO₂一个样本，因此并非完全未见体系；正文这部分没有为整条扫描提供独立真实带隙对照。[C16] 对稀疏新体系和跨性质迁移，作者用的是未来可研究、相信可能的表述。[C17] 这不否定方法的筛选潜力，但不足以把趋势图当作已验证发现能力。

重复性证据需要分层理解：第3页明确称钢任务重复训练验证均好于Automatminer最佳95.2 GPa，这是局部定性证据。[C18] 第7页又说明全部CrabNet训练固定种子42；固定种子和Matbench五折不能替代所有任务的多初始化均值、方差或优势显著性。[C19][C22] 模型确有偶然不确定性输出，图5灰色带即此；但作者明确尚未研究利用运行间差异估计认知不确定性，故不能把图5灰带理解成未见化学体系的可靠覆盖保证。[C20][C21] 依据：p03-b01、p07-b03—b05、p06-b04。

## 适用条件、未知与最小后续动作

可据此选择CrabNet作为组成回归候选，先限定目标性质、标签来源和误差容限，并确认候选数据与训练标签定义一致；若要区分同组成的相或工艺差异，需补入相应信息或另作验证。[C02][C05][C25] 当前无法确定题设未见体系的误差、排序命中率、实验成功率及不确定性校准，也无法补全所有任务的多种子统计。[C22][C24]

最小必要后续阅读按决策顺序为：

1. 获取本文Supplementary Methods与目标数据的处理/划分说明，核对去重后样本数、标签选择、是否存在真正按化学体系留出的测试，以及钢任务原始单位；本文p02-b03、p08-b02—b03给出资料线索。本次没有读取这些外部资料。[C05][C22][C23]
2. 若比较Automatminer或IRNet关系影响选型，只追读对应任务的原始基准设定，核对输入、划分及调参，不泛读无关方法。[C09][C12][C14]
3. 若决定投入未见体系筛选，先寻找与目标元素组合、性质和分布相符的外推验证及校准证据；若仍缺失，再设计按体系留出的验证、多种子比较及少量独立候选核验，设定可接受MAE和筛选指标。这是后续建议，本次未执行训练、筛选或实验。[C15][C20][C24]
